# 「ALYBH」合集

**该系列资源包现已没有正式发布链接，暂无后续发布计划**。

本页面仅留作档案查阅和记录。

## 内容简介

「ALYBH」合集是一套 Minecraft 简约风格纹理包，包含 ALYBH、ALYBH-2（ALYBHv2）、ALYBH-3（ALYBHv3）三个迭代版本。

## 基本功能

将绝大部分原版纹理替换为简约或带有个人特色的风格。

配合 OptiFine 使用可以获得一些额外功能，例如随机生物纹理、自定义光照等。

## 兼容性

不同的迭代版本分别适用于 **Minecraft Java 版 1.7.x–1.12.x** 。

部分高级功能需要安装的游戏版本同时兼容对应的前置模组。

## 花絮趣闻

- **是的，“ALYBH”就是这一套资源包的名字。** 作者 ALYBH 当时并没有大范围分发这些资源包的打算，仅对其进行了小范围的分享，因此它们没有任何正式定名。
- 这些资源包最早于 2014–2015 年制作。预期用途除满足审美需求外，也借由简化贴图降低游戏运行性能开销。
- 资源包封面上绘制的品红色史莱姆是吉祥物。 
- [ALYBH式重构（ALYBH-REconstruction）](./alybh-re-construction.md)基本可以视为该资源包合集的重置版。
