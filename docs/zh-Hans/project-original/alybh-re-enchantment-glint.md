## 内容简介

本资源包系列通过 **替换游戏内的光效（Glint）纹理，为《Minecraft》带来焕然一新又不失原版风格的光效**，无需安装任何模组即可直接使用。此外，本资源包系列还提供了多种不同风格的光效替代方案。

所有效果均基于资源包实现，不会修改游戏机制，安装简单，可作为原版光效的美化替换，为装备、物品等带来更加鲜艳、生动且富有层次感的视觉表现。

## 兼容性

### 适用版本

适用于 **《Minecraft》Java 版 1.15 及以上**的版本。

由于《Minecraft》于 Java 版 1.19.4 对附魔光效渲染方式进行了调整，**该资源包的视觉效果会在 1.19.4 前后的不同版本出现部分差异**。

在 **《Minecraft》Java 版 1.19.4 及以上**，可以通过修改游戏内的 **辅助功能设置** 来进一步自定义游戏内显示的光效强度以及动画速度，这同样也会适用于此类资源包。

**少部分资源包也能兼容其他游戏版本**，但效果欠佳（详见下文“细节”）。

<details>

<summary>细节</summary>

在 **较低版本的《Minecraft》Java 版（低于 1.15）** 以及 **《Minecraft》基岩版** 中，本系列资源包虽然可以加载，但视觉效果会有所受损，仅有少数情况下能够实现较为符合预期的颜色替换效果 **（例如蓝色 -> 紫色 -> 红色之间的换色）** 。

**这一问题无法仅通过修改资源包中的纹理文件解决，因为这些版本采用了与支持版本不同的光效渲染管线**。如需在这些版本中获得类似效果，通常需要借助模组、修改着色器或修改游戏内部文件等方式实现，例如采用高清修复（OpfiFine）中的 CIT-Enchantment 功能。

**直接在这些版本中使用此类资源包时，光效的换色效果会明显减弱，难以达到预期，而绘制在纹理上的图案也无法正常显示。** 实际上，仅蓝色、紫色与红色之间的颜色替换能够较好地保留效果；若使用其他颜色，或在纹理中绘制复杂图案，则最终呈现的效果往往不明显，甚至与预期完全不符。

**这是因为这些版本中的光效颜色由游戏内部渲染管线决定，为固定的紫色。** 光效纹理不会像支持的版本那样直接作为最终显示的图像，而是作为颜色乘数参与颜色混合，其 RGB 通道仅用于影响各颜色通道的最终强度，因此无法忠实还原纹理本身的颜色和细节。由于该固定紫色主要由红色与蓝色组成，仅包含极少量绿色，因此 **蓝色、紫色与红色能够相对较好地保留，而绿色、黄色、青色等其他颜色则会发生明显偏色或亮度损失。**

**此外，不建议仅通过转换文件结构完成兼容，就将这类资源包移植至基岩版（除非你的目的刚好符合上述的限制条件，例如只是想要个蓝色的光效）。** 除了同样存在上文所述的限制之外，《Minecraft》基岩版的光效渲染流程还会对最终的光效纹理进行进一步的采样处理，使纹理细节更容易出现模糊或像素化现象，因此图案的表现效果会进一步下降。

</details>
