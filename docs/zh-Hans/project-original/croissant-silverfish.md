# 可颂包蠹虫（Croissant Silverfish）

> 可颂面包主题的蠹虫纹理以及模型，给游戏增添烘焙风的趣味幽默感。

<details>
<summary>点击展开发布页面</summary>

- Modrinth：https://modrinth.com/project/rNKiWRiR
</details>


## 内容简介

这是一款充满创意的 Minecraft 资源包，将原本令人毛骨悚然的蠹虫变成了一群活泼可爱的可颂面包生物。

玩家将不再遇见原版昆虫般的蠹虫，而是遇见外表金黄酥脆、灵感源自可颂面包的趣味生物，为地下探索增添轻松幽默的氛围。

无论你喜欢美食主题、美化整活风格的资源包，还是只是想让自己的 Minecraft 世界变得更加美味、少一点惊悚，这款资源包都非常适合你。

## 兼容性

### 适用版本

兼容 **《Minecraft》Java 版 1.6 及以上版本** 。

原版游戏中，蠹虫刷怪蛋的纹理与模型仅在 1.13 及以上版本可用。

### 占用资源

**原版游戏：**

- 纹理：蠹虫，蠹虫刷怪蛋（模型）
- 模型：蠹虫（占用原版内置模型），蠹虫刷怪蛋
