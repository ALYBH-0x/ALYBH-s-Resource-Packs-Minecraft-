# 萌萌方蠹虫（Cute Blocky Silverfish）

> 重新设计蠹虫外观，使其更加符合方块风格，同时可爱度又提升了 20%！此外，配合游戏模组使用还可以实现额外功能。

<details>
<summary>点击展开发布页面</summary>

- Modrinth：https://modrinth.com/project/bFOqsU0k
- Planet Minecraft：https://www.planetminecraft.com/texture-pack/cute-blocky-silverfish/
</details>

## 内容简介

这款轻量级资源包为蠹虫（Silverfish）相关的纹理和模型带来了全新的方块化外观。它将蠹虫重新设计为类似于末影螨（Endermite）的方块风格。

对于希望让这些小虫子看起来更加亲切、可爱，又不想安装任何模组或修改游戏机制的玩家来说，这是一个简单而自然的视觉美化选择。

当然，如果您选择搭配合适的模组（详见本页面的“兼容性”条目），这款资源包还能为蠹虫和它的刷怪蛋带来更多风味变种。

## 基本功能

替换蠹虫、蠹虫刷怪蛋以及寄生状态效果图标的纹理贴图，并新增蠹虫刷怪蛋的物品模型和对应纹理，**使游戏中蠹虫相关的视觉元素呈现更方块化的外观**。

资源包提供两种原版蠹虫刷怪蛋样式：**模型替换版**、**纹理替换版**；如需仅保留纹理替换效果，移除资源包内对应的模型文件即可切换。

其中**模型替换版**经过专门设计，作为头戴装备佩戴、或是放入物品展示框时，能够呈现不同于常规物品的观赏效果。

> 注意：额外功能中的“物品外观变种”仅支持模型，该切换方式**不适用**于物品外观变种。

## 实体外观变种

根据蠹虫的**自定义名称**或**生成所在的方块类型**为其应用不同的外观，使不同来源的蠹虫拥有更加丰富且独特的视觉表现。

大部分情况下，蠹虫都会根据其生成时所关联的方块类型选择符合环境的外观，并带有一定的随机权重，使同一来源类型的蠹虫也具有一定的外观差异。这些外观也可以通过命名牌直接触发或更改。

## 兼容性

### 适用版本

兼容 **《Minecraft》Java 版 1.6 及以上版本** 。

原版游戏中，蠹虫刷怪蛋的纹理与模型仅在 1.13 及以上版本可用。

为 Java 版 1.6–1.21.10 制作的资源包通常也可在部分更高版本中使用，但模型显示效果由于旧版模型格式可能无法完全符合预期。

部分高级功能需要安装的游戏版本同时兼容对应的前置模组。

### 额外需求

以下功能需要对应的前置才能够实现：

**实体外观变种：**
选择以下其中一种安装即可：

- 支持实体纹理特性（Entity Texture Features，ETF）自定义实体功能的模组；
- 支持高清修复（OptiFine）自定义实体纹理功能的模组。

> 建议优先选择支持实体纹理特性（ETF）功能的模组，因为该资源包预设的部分功能为此类模组独有，且实体纹理特性（ETF）模组本身即支持高清修复（OptiFine）自定义实体纹理功能。
> 
> 部分功能可能暂不支持扁平化更新前（即 Java 版 1.13 之前）的游戏版本。

**物品外观变种：**

- 支持自定义物品纹理（Custom Item Textures，CIT）功能的模组，例如高清修复（OptiFine）或 CIT Resewn 等。

### 占用资源

**原版游戏：**

- 纹理：蠹虫，蠹虫刷怪蛋（物品、模型），寄生状态效果图标
- 模型：蠹虫（占用原版内置模型），蠹虫刷怪蛋

**自定义实体纹理：**

- 纹理：蠹虫

**自定义物品纹理：**

- 纹理：蠹虫刷怪蛋
- 模型：蠹虫刷怪蛋
