# 主页

欢迎访问！本 Wiki 主要用于介绍资源包们的具体内容。

您可以在页面顶部选择对应页面所支持的语言，或在下方的文档导航处选择想要浏览的内容，点击即可直接跳转。如果不同页面的内容理解存在分歧，请以简体中文版本为准 **（许可证的正文除外）**。

如需下载或使用其中的资源包（感谢！），请注意各个资源包对应的内容使用规约或许可协议。使用时，请参阅下文提到的安装说明。

**注意：请不要将其用于未被明确授权的用途。** 如果不确定您的用途是否被授权，或需要获取明确的书面授权，请联系作者。感谢您的配合、理解与支持。

此外，**这些资源包是免费的！如果您曾为这些资源包付款，请注意您可能已上当受骗。**
