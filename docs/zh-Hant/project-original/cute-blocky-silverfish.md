# 萌萌方蠹蟲（Cute Blocky Silverfish）

> 重新設計蠹蟲外觀，使其更加符合方塊風格，同時可愛度又提升了 20%！此外，配合遊戲模組使用還可以實現額外功能。

<details>

- Modrinth：https://modrinth.com/project/bFOqsU0k
- Planet Minecraft：https://www.planetminecraft.com/texture-pack/cute-blocky-silverfish/
</details>

## 內容簡介

這款輕量級資源包爲蠹蟲（Silverfish）相關的紋理和模型帶來了全新的方塊化外觀。它將蠹蟲重新設計爲類似於末影蟎（Endermite）的方塊風格。

對於希望讓這些小蟲子看起來更加親切、可愛，又不想安裝任何模組或修改遊戲機制的玩家來說，這是一個簡單而自然的視覺美化選擇。

當然，如果您選擇搭配合適的模組（詳見本頁面的“兼容性”條目），這款資源包還能爲蠹蟲和它的刷怪蛋帶來更多風味變種。

## 基本功能

替換蠹蟲、蠹蟲刷怪蛋以及寄生狀態效果圖標的紋理貼圖，並新增蠹蟲刷怪蛋的物品模型和對應紋理，**使遊戲中蠹蟲相關的視覺元素呈現更方塊化的外觀**。

資源包提供兩種原版蠹蟲刷怪蛋樣式：**模型替換版**、**紋理替換版**；如需僅保留紋理替換效果，移除資源包內對應的模型文件即可切換。

其中**模型替換版**經過專門設計，作爲頭戴裝備佩戴、或是放入物品展示框時，能夠呈現不同於常規物品的觀賞效果。

> 注意：額外功能中的“物品外觀變種”僅支持模型，該切換方式**不適用**於物品外觀變種。

## 實體外觀變種

根據蠹蟲的**自定義名稱**或**生成所在的方塊類型**爲其應用不同的外觀，使不同來源的蠹蟲擁有更加豐富且獨特的視覺表現。

大部分情況下，蠹蟲都會根據其生成時所關聯的方塊類型選擇符合環境的外觀，並帶有一定的隨機權重，使同一來源類型的蠹蟲也具有一定的外觀差異。這些外觀也可以通過命名牌直接觸發或更改。

## 兼容性

### 適用版本

兼容 **《Minecraft》Java 版 1.6 及以上版本** 。

原版遊戲中，蠹蟲刷怪蛋的紋理與模型僅在 1.13 及以上版本可用。

爲 Java 版 1.6–1.21.10 製作的資源包通常也可在部分更高版本中使用，但模型顯示效果由於舊版模型格式可能無法完全符合預期。

部分高級功能需要安裝的遊戲版本同時兼容對應的前置模組。

### 額外需求

以下功能需要對應的前置才能夠實現：

**實體外觀變種：**
選擇以下其中一種安裝即可：

- 支持實體紋理特性（Entity Texture Features，ETF）自定義實體功能的模組；
- 支持高清修復（OptiFine）自定義實體紋理功能的模組。

> 建議優先選擇支持實體紋理特性（ETF）功能的模組，因爲該資源包預設的部分功能爲此類模組獨有，且實體紋理特性（ETF）模組本身即支持高清修復（OptiFine）自定義實體紋理功能。
> 
> 部分功能可能暫不支持扁平化更新前（即 Java 版 1.13 之前）的遊戲版本。

**物品外觀變種：**

- 支持自定義物品紋理（Custom Item Textures，CIT）功能的模組，例如高清修復（OptiFine）或 CIT Resewn 等。

### 佔用資源

**原版遊戲：**

- 紋理：蠹蟲，蠹蟲刷怪蛋（物品、模型），寄生狀態效果圖標
- 模型：蠹蟲（佔用原版內置模型），蠹蟲刷怪蛋

**自定義實體紋理：**

- 紋理：蠹蟲

**自定義物品紋理：**

- 紋理：蠹蟲刷怪蛋
- 模型：蠹蟲刷怪蛋
