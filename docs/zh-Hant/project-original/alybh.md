# 「ALYBH」合集

**該系列資源包現已沒有正式發佈鏈接，暫無後續發佈計劃**。

本頁面僅留作檔案查閱和記錄。

## 內容簡介

「ALYBH」合集是一套 Minecraft 簡約風格紋理包，包含 ALYBH、ALYBH-2（ALYBHv2）、ALYBH-3（ALYBHv3）三個迭代版本。

## 基本功能

將絕大部分原版紋理替換爲簡約或帶有個人特色的風格。

配合 OptiFine 使用可以獲得一些額外功能，例如隨機生物紋理、自定義光照等。

## 兼容性

不同的迭代版本分別適用於 **Minecraft Java 版 1.7.x–1.12.x** 。

部分高級功能需要安裝的遊戲版本同時兼容對應的前置模組。

## 花絮趣聞

- **是的，“ALYBH”就是這一套資源包的名字。** 作者 ALYBH 當時並沒有大範圍分發這些資源包的打算，僅對其進行了小範圍的分享，因此它們沒有任何正式定名。
- 這些資源包最早於 2014–2015 年製作。預期用途除滿足審美需求外，也藉由簡化貼圖降低遊戲運行性能開銷。
- 資源包封面上繪製的品紅色史萊姆是吉祥物。 
- [ALYBH式重構（ALYBH-REconstruction）](./alybh-re-construction.md)基本可以視爲該資源包合集的重置版。
