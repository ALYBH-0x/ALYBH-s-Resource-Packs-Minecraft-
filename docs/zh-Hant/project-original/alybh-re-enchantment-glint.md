# 「ALYBH 的 重繪附魔光效（ALYBH‐REnchantment Glints）」合集

 > 附魔光效資源包合集，提供幾十種不同色彩、漸變、紋樣風格的附魔閃爍光效替換方案，且無需模組即可使用。

## 內容簡介

本資源包系列通過 **替換遊戲內的光效（Glint）紋理，爲《Minecraft》帶來煥然一新又不失原版風格的光效**，無需安裝任何模組即可直接使用。此外，本資源包系列還提供了多種不同風格的光效替代方案。

所有效果均基於資源包實現，不會修改遊戲機制，安裝簡單，可作爲原版光效的美化替換，爲裝備、物品等帶來更加鮮豔、生動且富有層次感的視覺表現。

## 兼容性

### 適用版本

適用於 **《Minecraft》Java 版 1.15 及以上**的版本。

由於《Minecraft》於 Java 版 1.19.4 對附魔光效渲染方式進行了調整，**該資源包的視覺效果會在 1.19.4 前後的不同版本出現部分差異**。

在 **《Minecraft》Java 版 1.19.4 及以上**，可以通過修改遊戲內的 **輔助功能設置** 來進一步自定義遊戲內顯示的光效強度以及動畫速度，這同樣也會適用於此類資源包。

**少部分資源包也能兼容其他遊戲版本**，但效果欠佳（詳見下文“細節”）。

<details>

<summary>細節</summary>

在 **較低版本的《Minecraft》Java 版（低於 1.15）** 以及 **《Minecraft》基岩版** 中，本系列資源包雖然可以加載，但視覺效果會有所受損，僅有少數情況下能夠實現較爲符合預期的顏色替換效果 **（例如藍色 -> 紫色 -> 紅色之間的換色）** 。

**這一問題無法僅通過修改資源包中的紋理文件解決，因爲這些版本採用了與支持版本不同的光效渲染管線**。如需在這些版本中獲得類似效果，通常需要藉助模組、修改着色器或修改遊戲內部文件等方式實現，例如採用高清修復（OpfiFine）中的 CIT-Enchantment 功能。

**直接在這些版本中使用此類資源包時，光效的換色效果會明顯減弱，難以達到預期，而繪製在紋理上的圖案也無法正常顯示。** 實際上，僅藍色、紫色與紅色之間的顏色替換能夠較好地保留效果；若使用其他顏色，或在紋理中繪製複雜圖案，則最終呈現的效果往往不明顯，甚至與預期完全不符。

**這是因爲這些版本中的光效顏色由遊戲內部渲染管線決定，爲固定的紫色。** 光效紋理不會像支持的版本那樣直接作爲最終顯示的圖像，而是作爲顏色乘數參與顏色混合，其 RGB 通道僅用於影響各顏色通道的最終強度，因此無法忠實還原紋理本身的顏色和細節。由於該固定紫色主要由紅色與藍色組成，僅包含極少量綠色，因此 **藍色、紫色與紅色能夠相對較好地保留，而綠色、黃色、青色等其他顏色則會發生明顯偏色或亮度損失。**

**此外，不建議僅通過轉換文件結構完成兼容，就將這類資源包移植至基岩版（除非你的目的剛好符合上述的限制條件，例如只是想要個藍色的光效）。** 除了同樣存在上文所述的限制之外，《Minecraft》基岩版的光效渲染流程還會對最終的光效紋理進行進一步的採樣處理，使紋理細節更容易出現模糊或像素化現象，因此圖案的表現效果會進一步下降。

</details>
