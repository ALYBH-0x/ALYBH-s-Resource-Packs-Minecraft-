# 聯繫方式

本頁爲聯繫方式說明頁，您可以查看溝通渠道、適用場景以及聯繫須知。

[返回主頁](./home.md)

## 溝通渠道

### GitHub Issues

鏈接：https://github.com/ALYBH-0x/ALYBH-s-Resource-Packs-Minecraft-/issues

**適用場景：** 提交 Bug 反饋、文檔修正等需要倉庫、項目頁面維護方進行修改、落地修復的問題。

> 提交前請檢索是否存在重複 Issue；重複問題優先在原有單下面補充信息；維護者會酌情處理，不保證限時響應。

### 電子郵件

Email：`ALYBH-0x@outlook.com`

**適用場景：** 發送重要信息，包括但不限於正式許可諮詢、授權申請、合作洽談；以及需要留存書面記錄、規範流轉和及時回覆的場合。

> 郵件一般會在 7 個自然日內處理；若逾期未收到回覆，請檢查垃圾郵件文件夾，或嘗試重新發送郵件。在同樣的時限內，如進行正式郵件往來時沒有收到您的回信，我會酌情主動跟進確認。

### 其他

**社媒私信：**

嗶哩嗶哩：https://space.bilibili.com/3707013659888454

**適用場景：** 簡短告知、簡單私下溝通等。

> 此類聯繫方式僅作爲非正式補充聯絡渠道，通過該渠道發送的消息不保證回覆。屬於前文所列渠道已覆蓋的事項，不建議通過私信發送。

## 說明

- 請優先按事項選擇對應溝通渠道。當您通過合適渠道發送消息，逾期仍未收到回覆時，請先查閱該渠道的聯繫須知；如確有需要，可嘗試通過本文所列的其他渠道進行提醒。
- 發送諮詢消息時，建議同步附上相關背景資料、需求細節等必要信息，便於快速覈實情況並處理。
- 除非發生緊急情況，請儘量不要使用本文沒有列出的其他聯繫方式，通過這類渠道發送的消息很難收到回覆。
- 無關廣告、商業推廣信息，或是內容空泛、訴求模糊，無法清晰說明自身需求與相關背景的消息，恕不予以回覆。
