> Redesigns silverfish to fit a blockier aesthetic while boosting cuteness by an extra 20%! Additional features are available when paired with compatible mods.

## Overview

This lightweight resource pack brings brand new blocky textures and models to silverfish. It reimagines silverfish with a block style similar to the Endermite.

It is a simple, subtle visual upgrade for players who want these little mobs to look friendlier and cuter, without installing mods or changing gameplay mechanics.

If you use compatible mods (see Compatibility section below), this pack also unlocks extra variant appearances for silverfish and its spawn egg.

## Core Features

Replaces textures for silverfish, silverfish spawn egg and the infestation status effect icon. It also adds a custom item model and matching texture for the silverfish spawn egg, **giving all silverfish-related visuals in-game a more blocky look**.

Two variants of the vanilla silverfish spawn egg are included: **Model Variant** and **Texture-Only Variant**. To keep only the texture change, delete the corresponding model file inside the pack.

The **Model Variant** is specially designed to look unique when worn as a head item or placed inside an Item Frame.

> Note: The extra "item appearance variants" only work with models. This toggle method **does not apply** to item appearance variants.

## Entity Appearance Variants

Silverfish can display different appearances based on their **custom name** or the **block they spawn from**, giving silverfish from different sources richer, unique visuals.

In most cases, silverfish pick an appearance matching the block they spawn in, with weighted randomness. Silverfish from the same block type can still have visual variety. Variants can also be directly triggered or changed using a Name Tag.

## Compatibility

### Supported Versions

Compatible with **Minecraft Java Edition 1.6 and newer**.

In vanilla Minecraft, custom textures and models for the silverfish spawn egg only work in 1.13 and newer.

Packs built for Java Edition 1.6–1.21.10 may run on some newer releases, though model rendering may not behave as expected due to older model formats.

Advanced extra features require a game version compatible with the required dependency mods.

### Dependencies

The following features require supporting mods:

**Entity Appearance Variants:**
Install one of the following:
- Mods supporting Entity Texture Features (ETF) custom entity textures;
- Mods supporting OptiFine custom entity textures.

> ETF-supporting mods are recommended first, since some built-in features of this pack are exclusive to ETF. ETF also supports OptiFine custom entity texture functionality.
>
> Some features may not work on pre-flattening Java versions (before 1.13).

**Item Appearance Variants:**
- Mods supporting Custom Item Textures (CIT), such as OptiFine or CIT Resewn.

### Resource Usage

**Vanilla Minecraft:**
- Textures: silverfish, silverfish spawn egg (item + model), infestation status icon
- Models: silverfish (uses vanilla internal model), silverfish spawn egg

**Custom Entity Textures:**
- Textures: silverfish

**Custom Item Textures:**
- Textures: silverfish spawn egg
- Models: silverfish spawn egg
