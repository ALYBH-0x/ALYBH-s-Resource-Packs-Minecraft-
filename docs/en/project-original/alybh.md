# ALYBH Collection

**There are no official download links available for this series of resource packs, and no further releases are planned.**

This page is kept only for archival reference.

## Overview

The ALYBH Collection is a set of minimalist Minecraft texture packs with three iterative versions: ALYBH, ALYBH-2 (ALYBHv2), and ALYBH-3 (ALYBHv3).

## Core Features

Replaces most vanilla textures with a minimalist and stylized custom aesthetic.

Extra features are available when used with OptiFine, such as random mob textures and custom lighting.

## Compatibility

Different iterations target **Minecraft Java Edition 1.7.x–1.12.x**.

Some advanced features require compatible supporting mods for your game version.

## Trivia

- **Yes, "ALYBH" is the name of this collection.** The author ALYBH originally had no intention of widely distributing these packs; they were only shared within a small circle and never received an official name.
- These packs were first created around 2014–2015. Besides visual preference, simplified textures were also designed to reduce performance overhead.
- The magenta slime shown on the pack cover serves as its mascot.
- [ALYBH-REconstruction](./alybh-re-construction.md) can largely be considered the remake of this collection.
