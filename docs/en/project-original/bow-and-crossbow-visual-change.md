# Bow and Crossbow Visual Changes

> Swaps the first-person held visuals of bows and crossbows. It is also split into two standalone subpacks: Horizontal Bow and Vertical Crossbow for flexible combination.

## Overview

This pack swaps first-person held appearances for bows and crossbows by modifying model files: the bow appears horizontally and the crossbow vertically while aiming, offering an alternative visual style.

It is compatible with other resource packs that do not override the same target files, and its own effects will not be broken (see the Compatibility section below).

Two separate subpacks are also provided. They can be enabled individually or together and support older game versions. Their Modrinth pages are listed below:

- [[1.8+] Horizontal Bow](https://modrinth.com/project/HzjoCRJ2)
- [[1.14+] Vertical Crossbow](https://modrinth.com/project/xOoZ5LQr)

## Compatibility

### Supported Versions

**Bow and Crossbow Visual Changes** compatible with **Minecraft Java Edition 1.14 and newer**.

If you need support for older versions or want to toggle effects separately, use the two standalone subpacks mentioned in the Overview:

- **Horizontal Bow**: Compatible with **Minecraft Java Edition 1.8 and newer**
- **Vertical Crossbow**: Compatible with **Minecraft Java Edition 1.14 and newer**

> On **Minecraft Java Edition 1.14 and above**, the two subpacks are fully compatible with each other. Enabling both together yields nearly the same result as the full pack.
>
> **Minecraft Java Edition 1.8** uses the older item model format, so rendering may differ slightly compared with newer versions.

### Resource Usage

**Vanilla Minecraft:**

- Models: item models used for drawing/aiming bows and crossbows

> This pack works by replacing target Item Models, so it occupies those model files and may conflict with other packs that modify the same item models.
>
> Packs that only modify Textures without changing these item models can usually run alongside this pack without visual issues.

## Trivia

- This pack was inspired by shooter games that use side-stanced bow weapons in first-person view for better gameplay feel. The vertical crossbow was simply made to match the horizontal bow, just for fun.
- Coincidentally, real crossbows are traditionally horizontal, and bows can also be fired sideways in emergencies. The vertical crossbow concept resembles experimental vertical crossbows from the medieval era and modern vertical compound crossbows.
